# Acceptance checks

- Output parses against `OUTPUT_SCHEMA.json`.
- Every input `sectionKey` appears exactly once.
- A teammate can understand the change without opening the code.
- Test results appear once.
- Parameters are preserved and explained.
- Trace metadata stays out of the body.
- Quantitative claims have a matched baseline, or the missing experiment is stated.
- The last subsection is `参考代码和数据`.
- The prose contains no audit-system narration.
